# TH-1128 Store Detail Action Nudge Brief

## 00 Brief

- Jira: https://3dollarinmypocket.atlassian.net/browse/TH-1128
- 작성일: 2026-07-05
- 목표:
  - 가게 상세 화면에서 방문 인증, 신고/삭제, 정보 수정 액션을 더 쉽게 발견하고 실행할 수 있게 유도한다.
  - Figma 기준으로 기존 하단 고정 CTA 또는 바텀시트 진입 중심 UX에서, 조건 충족 시 상세 진입 후 자동 노출되는 플로팅/토스트형 유도 UI로 접근성을 높인다.
- 성공 기준:
  - 상세 화면 진입 후 조건에 맞는 유도 UI가 지정된 지연 시간과 애니메이션으로 노출된다.
  - 미클릭 상태에서는 지정 시간 이후 자동으로 사라진다.
  - 유도 UI 내부 액션을 누른 동안에는 자동 숨김 타이머가 사용자 액션을 방해하지 않는다.
  - 방문 인증 또는 신고하기 완료 후 완료 토스트/피드백이 표시된다.
  - 기존 상세 하단 버튼, 리뷰 작성, 정보 수정, 삭제 요청, 방문 인증 API 흐름은 회귀하지 않는다.
- In scope:
  - 유저 제보 가게 상세 화면(`StoreDetailActivity`)의 액션 유도 UI.
  - 방문 인증 유도 플로우.
  - 신고/삭제/정보 수정 유도 플로우.
  - 유도 UI 노출 조건, 노출/숨김 타이밍, 완료 피드백 상태 관리.
  - 필요한 경우 서버 API 응답/설정값 연동.
- Out of scope:
  - 사장님 가게 상세 화면(`BossStoreDetailActivity`) 적용 여부는 Jira/API에서 별도 확인 전까지 제외한다.
  - 방문 인증 화면 자체의 대규모 리디자인.
  - 삭제 요청 API 정책 변경.
  - 정보 수정 화면(`EditStoreFragment`) 전체 개편.
  - 리뷰 작성 플로우 변경.
- 관련 문서/디자인/API:
  - Figma: https://www.figma.com/design/NEiQWZyejXjMKjoQhMIw0S/MCP?node-id=882-10754&m=dev
  - Figma node: `882:10754` (`PO 방문인증 유도 / 신고,삭제, 정보 수정 유도`)
  - API/Jira: Jira 원문과 API Jira는 현재 세션에서 접근 불가. 구현 전 API 계약 확인 필요.

## Figma Summary

- 상위 섹션은 두 플로우를 포함한다.
  - `PO 방문인증 유도 Flow`
  - `PO 신고/삭제/정보 수정 유도`
- 공통 방향:
  - AS-IS: 상세 페이지 끝까지 진입하거나, 툴팁 CTA 및 바텀시트 버튼을 거쳐야 액션 가능.
  - TO-BE: 불필요한 과정을 제거하고 원탭 구조로 접근성을 높임.
- Figma에서 확인한 주요 타이밍:
  - 조건이 부합할 때 상세 진입 `500ms` 이후 플로팅 `Slide in`.
  - 미클릭 시 `3000ms` 이후 `Slide out`.
  - 토스트는 기본적으로 `3000ms` 이후 자동으로 사라짐.
  - 토스트 내부 버튼을 클릭 중인 경우 `3000ms`가 지나도 사라지지 않음.
  - 버튼 선택 이후 별도 추가 액션이 없으면 해당 액션 완료 시점부터 `3000ms` 후 `Slide out`.
