# TH-1401 2차 실행 기록

2026-10-07 사용자 승인: 1차 뷰와 최신 서버 계약을 합쳐 공통 SDUI 정리, API·데이터, 실홈 상태·링크·클릭 로그 연결, 유닛·화면 검증까지 진행한다.

- [x] 실응답 fixture 캡처, API·mapper RED → 구현 → GREEN.

- [x] 독립 리뷰·통합 유닛·빌드·에뮬레이터 검증.

## Rulings

- Ruling: 기존 작업 디렉터리와 미커밋 UI 변경을 이어 사용한다 — 1차 산출물과 사용자 artifacts/를 보존해야 한다 — 잘못되면 로컬 변경 재작업 비용이며 원격은 변경하지 않는다.
- Ruling: 공통 SDUI primitive를 사용하고 기존 홈/상세 파서는 통합하지 않는다 — 최신 계약과 기존 Gson 설정을 유지한다 — 잘못되면 해당 mapper 범위 재작업이다.
- Ruling: 같은 지도 조건에서 탭 왕복 시 선택/스크롤을 유지한다. 지도 재검색·주소 확정은 서버 기본 카테고리로 새 section을 조회한다 — 초기 cards가 기본 카테고리 응답이므로 선택/카드 불일치를 방지한다 — 잘못되면 복원 정책 재작업이다.
- Ruling: 기존 주변 마커를 병행 유지하고 전역 필터는 기존 목록/마커에만 적용한다 — 큐레이션 API에 기존 filter 계약이 없다 — 잘못되면 서버 계약/기획 조정이 필요하다.
- Ruling: 칩 로딩/실패 중 기존 선택·카드를 유지하고 성공 시 함께 교체한다 — 잘못된 카테고리 카드 표시를 방지한다 — 잘못되면 사용자 피드백에 따라 optimistic 표시만 바꾼다.
- Ruling: 실광고 SDK는 후속 범위이며 2차는 모델과 슬롯을 준비한다 — 가로100dp 슬롯과 기존 BANNER 규격이 다르다 — 광고 TC-7 전체 완료로 보고하지 않는다.
- Ruling: 개발 서버/에뮬레이터 검증에는 서울시청 공개 테스트 좌표를 사용한다 — 실응답 기반 fixture와 위치 검증이 필요하다 — 사용자 GPS/토큰은 조회하거나 공유하지 않는다.

## 승인·원격 범위

테크스펙 TC-1~12가 번호 원천이다. UI의 기존 TDD 예외를 유지하고 새 파싱/상태는 테스트부터 작성한다. 의존성·버전·원격 스펙·커밋·푸시·배포는 변경하지 않는다.
