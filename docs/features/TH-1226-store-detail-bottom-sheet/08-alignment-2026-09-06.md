# TH-1226 중앙 정렬 보정 — 2026-09-06

## 범위 및 결과

사용자 요청에 따라 중앙 정렬만 보정했다. 구분선, 색상, 서버 문자열·URL, 액션 정책은 변경하지 않았다.

- 아이콘 전용 버튼에서 빈 Text와 불필요한 간격을 제거했다. imageAlignment가 END인 경우도 텍스트가 없으면 가변 Spacer/fillMaxWidth를 만들지 않아 아이콘 자체를 가운데에 배치한다.
- REVIEW card의 trailing action을 닉네임의 첫 baseline과 맞췄다. 날짜가 포함된 전체 Column의 중앙을 기준으로 삼지 않는다.
- 기존 section header는 `alignActionWithTitle=false` 기본값을 유지하고, 리뷰 카드에서만 정렬 옵션을 사용한다. 버튼의 최소 터치 크기는 유지한다.

텍스트 baseline은 직접/간접 부모 layout으로 전달될 수 있다는 [Android 공식 alignment lines 문서](https://developer.android.com/develop/ui/compose/layouts/alignment-lines)를 확인한 뒤 기존 Row/Column 구조에 적용했다.

## 변경 파일

- `core/ui/.../serverdriven/ServerDrivenRenderer.kt`: 표시할 텍스트가 있는 경우에만 Text와 관련 간격을 배치.
- `app/.../storeDetail/v2/StoreDetailV2Content.kt`: 선택적으로 제목과 trailing action의 FirstBaseline을 맞춤.
- `app/.../storeDetail/v2/StoreDetailV2EngagementSections.kt`: 리뷰 카드에서 해당 옵션 활성화.
